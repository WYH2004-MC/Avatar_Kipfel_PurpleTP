# Triturbo Face Tracking Addon
Triturbo Face Tracking Framework is a modular, non-destructive system for face tracking in VRChat with [VRCFaceTracking](https://github.com/benaclejames/VRCFaceTracking).

## Dependencies
- [BlendShare](https://github.com/Tr1turbo/BlendShare)
- [Modular Avatar](https://github.com/bdunderscore/modular-avatar)
